# ✅ React To-Do List App

A simple and responsive to-do list application built with **React**. This app allows users to add, mark, and delete tasks, helping manage daily activities efficiently.

---

## 🚀 Live Demo

[🔗 View Live App](https://github.com/facebook/create-react-app)

---

## 🧰 Tech Stack

- ⚛️ React (Hooks + Functional Components)
- 🎨 CSS (or Tailwind)
- 📦 Local Storage (for saving tasks)

---

## ✨ Features

- ✅ Add new tasks  
- ✅ Mark tasks as complete/incomplete  
- ✅ Delete tasks  
- ✅ Task state saved in local storage  
- ✅ Responsive design
